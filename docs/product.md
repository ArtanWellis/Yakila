# Produit

Voir la vision complète dans [CLAUDE.md](../CLAUDE.md).

Question guide : cette fonctionnalité aide-t-elle réellement quelqu'un à trouver un service local ou à gagner de l'argent localement ?

## MVP

- Prestataire : compte → profil → ville → publier un service → visible dans la recherche locale → messagerie.
- Client : compte → rechercher → filtrer autour de soi → profil → contacter.
- Mission : publier → recevoir une candidature → contacter.
- YaKoiLa : publier un objet → découvert localement → messagerie.

## V1 et au-delà

Réservations par créneaux, offres/devis dans le chat, badges avancés, dashboard de revenus et objectifs, paiements (Stripe Connect), push et email, i18n.
